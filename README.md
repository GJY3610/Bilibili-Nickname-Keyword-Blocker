# B 站昵称关键词拉黑扩展

这是一个可直接加载到 Chromium 或 Edge 浏览器中的 Manifest V3 扩展，用来在网页端哔哩哔哩按用户昵称关键词匹配用户，并执行手动或自动拉黑。

## 当前能力

- 默认只扫描评论区，也可以手动关闭限制改为扫描当前页面
- 识别指向用户空间的昵称链接
- 按关键词命中后在昵称旁边插入提示和拉黑按钮
- <img width="597" height="174" alt="image" src="https://github.com/user-attachments/assets/12bb0812-1420-4ca5-ab84-870fcf712063" />

- 可选自动拉黑
- 可选弱化显示命中内容
- 在弹窗里维护关键词和最近处理记录

## 安装方式

1. 打开 Chromium 内核浏览器的扩展管理页，例如 `chrome://extensions/`（Egde浏览器为'edge://extensions/')
2. 开启“开发者模式”
3. 选择“加载已解压的扩展程序”
4. 在目录找到下载的文件夹打开 

## 使用说明

1. 点击扩展图标
2. 在“昵称关键词”里一行填写一个关键词
3. 点击“保存设置”
4. 保持“仅评论区生效”开启时，插件只会处理评论区昵称
5. 如果你想恢复原来的全页扫描，可以关闭“仅评论区生效”
6. 默认是手动拉黑模式；确认命中效果没问题后，再决定是否开启自动拉黑

## 说明与限制

- 当前版本是“边浏览边处理”：只有当匹配昵称出现在你访问到的页面里时，扩展才会识别并执行拉黑
- 依赖你已经登录哔哩哔哩网页端账号
- 拉黑调用的是哔哩哔哩网页关系接口，因此站点接口变更时可能需要同步调整
